# Rental Listings Scraper

## Назначение
Сбор объявлений краткосрочной аренды из публичных источников в CSV.

## Важные ограничения
- Проверка robots.txt **не выполняется**.
- Парсятся только публично доступные страницы без авторизации.
- Геокодинг использует Nominatim с жёсткими лимитами запросов и локальным кешем.
- Координаты могут быть неточными или отсутствовать.

## Возможности
- Site-specific селекторы через config.yaml
- Парсинг карточки и профиля владельца
- Определение валюты из цены (символ или ISO)
- Address status: full / partial / not_found
- Геокодинг с кешированием
- Resume батчами
- Тестовый режим (limit N)

## Запуск
Python 3.10+

pip install requests pyyaml beautifulsoup4 lxml

python scraper/main.py
